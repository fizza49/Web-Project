# EDUBUDGET
An free app for students to track their expenses and finances.

## OBJECTIVE
To empower students with simple, intuitive tools for tracking finances, managing budgets, and building healthy money habits that promote financial literacy and independence.

## TECH STACK
**MERN** 
### Frontend
* React.js: Component-based UI, Virtual DOM, hooks (useState, useEffect)
* React Router: Client-side routing, protected routes, URL params
* Tailwind CSS: Responsive design, gradients, shadows, glass effects
* Lucide React: Scalable, interactive icons 

### Backend
* Node.js & Express: Server-side JS, REST APIs, middleware, modular routes.
* MongoDB & Mongoose: NoSQL database, schemas for Users, Transactions, Budgets.
* JWT Authentication: Token-based login, protected routes, password reset.
* bcrypt.js: Secure password hashing and verification.
* Nodemailer: Sends emails for password resets and notifications.
* Express Validator: Validates and sanitizes user input.
